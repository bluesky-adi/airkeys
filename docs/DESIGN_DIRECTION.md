
# AIRKEYS
## Visual Identity and Design Direction

## 1. Creative Direction

AirKeys should feel like an interactive music publication combined with a digital instrument studio.

The visual experience should be editorial, tactile, expressive, and immersive.

It should not resemble a conventional SaaS dashboard or generic AI-generated website.

## 2. Design Keywords

- Editorial.
- Tactile.
- Musical.
- Expressive.
- Spatial.
- Minimal but characterful.
- Contemporary.
- Warm.
- Experimental.
- Responsive.

## 3. Visual Principles

### Strong typography

Typography should create hierarchy and personality.

Use distinctive display typography for major headings and a highly readable supporting typeface for controls and instructions.

### Intentional composition

Layouts should feel art-directed.

Use:
- Asymmetric compositions where appropriate.
- Deliberate spacing.
- Strong visual hierarchy.
- Carefully controlled negative space.
- Editorial image placement.

### Tactile interactions

Controls should feel interactive rather than decorative.

Use meaningful:
- Hover states.
- Press states.
- Active states.
- Transitions.
- Instrument feedback.

### Musical visual feedback

Sound and interaction should influence the interface.

Examples:
- Active piano keys respond to notes.
- Fingertip interaction produces spatial feedback.
- Sound intensity influences visual elements.
- Instrument controls communicate their current state.

## 4. Avoid

- Generic SaaS dashboard layouts.
- Excessive gradients.
- Glassmorphism everywhere.
- Random floating cards.
- Unnecessary neon effects.
- Excessive rounded containers.
- Generic AI-generated landing pages.
- Decorative controls that do nothing.
- Animations that interfere with usability.

## 5. Visual Reference Categories

Collect references from four categories.

### Editorial design
Music magazines, independent publications, art direction, typography and print layouts.

### Physical instruments
Synthesizers, piano interfaces, analog controls, hardware textures and instrument panels.

### Interactive websites
Creative web experiences, navigation, transitions, spatial composition and microinteractions.

### Generative art
Sound-reactive graphics, motion systems, particles and visual representations of music.

## 6. Initial Design Deliverables

- Color palette.
- Typography system.
- Spacing system.
- Component direction.
- Landing page concept.
- Instrument selection screen.
- Piano studio screen.
- Camera permission state.
- Tracking and calibration state.
- Active note feedback.

## 7. Interaction Design Requirements

- Camera permission must be understandable.
- Tracking initialization must communicate progress.
- Users must understand whether their hands are detected.
- Active notes must be visually identifiable.
- Tracking loss must be communicated clearly.
- Controls must remain usable while playing.
- Responsive behavior must be considered from the beginning.

## 8. Motion Principles

Motion should communicate cause and effect.

Examples:
- A key responds immediately when activated.
- Visual effects follow musical events.
- Interface transitions establish spatial continuity.
- Loading animations communicate actual system activity.

Avoid animation that exists only to decorate empty space.

## 9. Design Tools

Primary:
- Pinterest for reference collection.
- Figma for interface design.
- Browser DevTools for implementation verification.

Optional later:
- Blender for custom 3D assets.
- Canvas 2D or PixiJS for interactive visual systems.

## 10. Design Philosophy

AirKeys should look and feel like a creative instrument in its own right.

The interface is not merely a container for functionality.

It is part of the musical experience.
